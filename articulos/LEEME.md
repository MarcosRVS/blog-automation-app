# Entregables de cada boletín

Cada semana genera una carpeta `articulos/AAAA-MM-DD/` (fecha del día de
generación) con:

- `articulo.md` — versión en español (fuente de verdad).
- `articulo-en.md` — versión en inglés.
- `wordpress-es.html` — HTML listo para pegar en el editor de WordPress (ES).
- `wordpress-en.html` — HTML listo para pegar en el editor de WordPress (EN).
- `revision.md` — resultado del checklist de revisión y observaciones.
- `guion-locucion.txt` — guion adaptado para narración por voz.
- `podcast-episodio.mp3` — audio MP3 del boletín generado con `generate_audio_tts.py`.
